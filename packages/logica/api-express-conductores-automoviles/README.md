# API con Express + SQL: Conductores y Automoviles

## Ejecutar

1. Instala dependencias:

```bash
npm install
```

2. Inicia el servidor:

```bash
npm start
```

3. Abre en el navegador:

```text
http://127.0.0.1:3001
```

## Endpoints

- `GET /conductores`
- `GET /automoviles`
- `GET /conductoressinauto?edad=<numero>`
- `GET /solitos`
- `GET /auto?patente=<string>`
- `GET /auto?iniciopatente=<letra>`
