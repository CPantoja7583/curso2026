# Archivos y JSON - BancoEstado

## Ejecutar

```bash
npm start
```

Servidor:

```text
http://127.0.0.1:3006
```

## Funcionalidades

- Listar todos los clientes y sus cuentas
- Listar clientes con cuenta RUT
- Agregar cliente nuevo + cuenta RUT
- Agregar cliente nuevo + cuenta de AHORRO
- Agregar cuenta RUT a cliente existente
- Agregar cuenta de AHORRO a cliente existente
- Eliminar cliente y sus cuentas
- Eliminar cuenta RUT
- Eliminar cuenta de AHORRO
