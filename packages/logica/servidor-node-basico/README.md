# Servidor Web Basico con Node.js

## Ejecutar

```bash
npm start
```

El servidor queda disponible en:

```text
http://127.0.0.1:3000
```

## Endpoints

- `GET /`: muestra fecha y hora actual del servidor.
- `GET /random-data`: devuelve una palabra aleatoria de 3 a 10 letras en HTML.
- `PUT /random-data`: devuelve un numero entero aleatorio entre 10 y 50000 en HTML.
- Otros metodos en `/random-data`: responden texto plano indicando que el metodo aun no esta implementado.
